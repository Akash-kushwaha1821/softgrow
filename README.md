# Covid-19 Data Analysis Dashboard (India)

This project is an interactive Covid-19 data analysis dashboard built using Python and Streamlit.
It analyzes pandemic data to identify trends in confirmed cases, recoveries, and deaths across states in India, and presents insights through visualizations and an interactive map.

---

## Project Features

* Data cleaning and preprocessing using Pandas
* Time-series trend analysis of Covid cases
* State-wise comparison of confirmed, recovered, and death counts
* Correlation analysis using heatmaps
* Interactive filters for state selection
* Choropleth map visualization of India
* Dashboard built using Streamlit for easy interaction

---

## Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Plotly (for map visualization)
* Streamlit (dashboard framework)

---

## Dataset Information

The dataset contains daily Covid-19 statistics for Indian states and union territories, including:

* Date of record
* State/Union Territory name
* Confirmed cases
* Recovered cases
* Death counts

The data is used to analyze pandemic progression, recovery trends, and regional impact differences.

---

## ▶️ How to Run the Project

1. Install required libraries:

   pip install streamlit pandas numpy matplotlib seaborn plotly

2. Place the dataset file in the project folder.

3. Run the dashboard:

   streamlit run app.py
   
4. The dashboard will open automatically in your browser.


## Project Objective

The goal of this project is to demonstrate real-world data analysis skills by working with public health data, building visualizations, and creating an interactive dashboard for insights and decision-making.
